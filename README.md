# Achadinhos da Clarisse — site institucional

Páginas estáticas com os documentos públicos do projeto.

| página | para quê |
|---|---|
| `index.html` | apresentação e link dos grupos |
| `privacidade.html` | Política de Privacidade (LGPD) |
| `termos.html` | Termos de Uso |
| `exclusao-de-dados.html` | instruções de exclusão de dados |

Sem build, sem dependência, sem cookie, sem analytics. Servido pelo GitHub Pages.

Este repositório é **público de propósito**: a Meta exige URL pública de política de
privacidade para o app sair do modo de desenvolvimento. Nada de credencial ou código de
operação entra aqui — isso fica no repositório privado do projeto.
